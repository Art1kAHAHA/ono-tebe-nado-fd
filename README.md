🎨 Ono tebe nado (Верстка)
Архивный учебный проект по верстке, выполненный в рамках курса по веб-разработке (2025 год).
В настоящее время активная разработка ведется в направлении бэкенда.

📌 О проекте
Данный проект представляет собой адаптивный веб-сайт, сверстанный по предоставленному макету.
Основной упор при разработке делался на семантическую структуру HTML, гибкую верстку с использованием современных CSS-технологий, а также на соблюдение чистоты и читаемости кода.
Проект сохранен в портфолио как наглядная демонстрация базовых навыков HTML/CSS и понимания принципов работы с DOM-структурой.

🚀 Запуск локально
Поскольку это статический сайт, для его запуска не требуется установка дополнительных инструментов (сборщиков или серверов).

Склонируйте репозиторий:

bash
git clone https://github.com/Art1kAHAHA/ono-tebe-nado-fd.git
Откройте файл index.html в любом современном браузере (Chrome, Firefox, Edge, Safari).

✨ Особенности верстки
✅ Адаптивность: Сайт корректно отображается на различных устройствах (от мобильных телефонов до широкоформатных мониторов).

✅ Семантический HTML: Использование тегов <header>, <main>, <section> и <footer> для логической структуры страницы.

✅ Современный CSS: Применены Flexbox и Grid для построения сложных сеток и выравнивания элементов.

✅ Чистота кода: Соблюдена читаемость и правильная вложенность селекторов.

🎯 Цели проекта
Закрепить навыки верстки и стилизации веб-страниц.

Понять принципы адаптивного и кросс-браузерного дизайна.

Научиться верстать по готовому макету без использования тяжелых фреймворков.
