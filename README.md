## 📌 О проекте

**«Оно тебе надо»** — это один из моих первых учебных проектов в процессе изучения веб-разработки.

Проект был создан для закрепления основ frontend-разработки: работы с HTML, CSS, адаптивной вёрсткой и структурой веб-страниц.

Сейчас мой основной интерес направлен в сторону **Backend-разработки**, но этот проект является частью моего пути в IT и показывает первые шаги в создании веб-приложений.
