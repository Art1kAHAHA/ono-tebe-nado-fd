## 📌 О проекте

**«Оно тебе надо»** — это одностраничный сайт, созданный в рамках обучения фронтенд-разработке.

Проект посвящён теме борьбы с прокрастинацией и показывает, как с помощью современных технологий можно создавать стильные и адаптивные веб-страницы.

Главная цель проекта — практика:
- 📐 работы с HTML-разметкой
- 🎨 стилизации через CSS
- 📱 создания адаптивного интерфейса
- 🧩 работы с файловой структурой проекта
